# Resultados

El análisis permitió identificar diferencias regionales en indicadores relacionados con educación y medio ambiente.

Las visualizaciones desarrolladas facilitaron la comparación de tendencias entre entidades federativas y permitieron detectar áreas prioritarias para el cumplimiento de los Objetivos de Desarrollo Sostenible.

El dashboard final integró información proveniente de distintas fuentes del INEGI para apoyar la interpretación de los datos.
